Entry for the [make.fun](https://make.fun/c/u-mang-the-printer-finally-answers-8fbf0907) bounty **The Printer Finally Answers**: one line, 1 to 240 characters, in the office printer's own voice — its comeback to the jams, the error codes and the thumps.

## How it works

`main.ts` (Node 22, no network, fully deterministic) writes a single line of 94 characters to `/output/entry.txt`:

> 41,208 sheets fed, 312 thumps taken. ERROR 49 means Job 47 from March prints before yours now.

Run it with:

```sh
node main.ts
```

The output directory can be overridden with the `OUTPUT_DIR` environment variable.
